### Esta applicacion cumple con los siguientes requisitos:

- [x] **Patrón MVVM**: La aplicación sigue el patrón de diseño Modelo-Vista-VistaModelo para una arquitectura organizada y mantenible.

- [x] **Inyección de dependencias con Dagger Hilt**: Se utiliza Dagger Hilt para la inyección de dependencias, facilitando la gestión de componentes y la creación de instancias.

- [x] **Corrutinas**: Las corrutinas de Kotlin se utilizan para realizar operaciones asíncronas de manera eficiente y concurrente.

- [x] **Estructura basada en Clean Architecture**: La aplicación sigue una estructura de Clean Architecture, separando claramente las capas de presentación, dominio y datos.

- [x] **Consumo de API**: La aplicación realiza el consumo de la API https://api.chucknorris.io/ para obtener y mostrar datos en la interfaz de usuario.

- [x] **Kotlin Flow**: Kotlin Flow se implementa para gestionar secuencias de datos de manera reactiva, proporcionando un flujo continuo de información entre el ViewModel y la interfaz grafica.
